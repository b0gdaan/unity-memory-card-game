Memory Card Game

A 6×6 card matching game built in Unity. Find all pairs, track your score, and beat your attempts record.

View Source on GitHub Read Paper (PDF)

How It Works

🃏

6×6 Grid

36 cards with 4 unique image pairs, randomly shuffled each game using Fisher-Yates algorithm.

🔍

Pair Matching

Click to reveal a card. Find its matching pair. Mismatches flip back after 0.5s delay via Coroutine.

🏆

Score Tracking

Score increments for each matched pair. Total attempts counted. Both displayed via TextMesh.

🔄

Instant Restart

Restart button reloads the scene, reshuffles cards and resets all counters instantly.

// Fisher-Yates shuffle for random card placement
private int[] Randomiser(int[] locations) {
    int[] array = locations.Clone() as int[];
    for (int i = 0; i < array.Length; i++) {
        int j = Random.Range(i, array.Length);
        (array[i], array[j]) = (array[j], array[i]);
    }
    return array;
}

// Coroutine-based match checking
private IEnumerator CheckGuessed() {
    if (firstOpen.spriteId == secondOpen.spriteId) {
        score++;
        scoreText.text = "Score: " + score;
    } else {
        yield return new WaitForSeconds(0.5f);
        firstOpen.Close();
        secondOpen.Close();
    }
    attempts++;
    attemptsText.text = "Attempts: " + attempts;
}
